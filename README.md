# Eye strain relief

安卓屏幕使用时长提醒工具。屏幕累计使用达到阈值后，弹出一个遮盖全屏、不可滑走的休息浮窗，倒计时结束自动消失。

## 当前状态

P1：真机（25098PN5AC / Android 17 / HyperOS OS4.0）验证通过。采用「全屏遮挡 + 切走即重置顶」策略：
不做系统级锁定（`am task lock` 会连带锁屏），浮窗以无障碍 overlay 覆盖全屏，用户用手势离开时
监听窗口变化并把浮窗重新挂到最上层，25 秒内始终无法绕开遮挡。注视数据源在该机型不可用，
当前走亮屏计时分支。

## 功能口径

| 项 | 规则 |
|---|---|
| 计数方式 | 累计，切换应用不清零 |
| 熄屏清零 | 单次连续熄屏超过 20 秒即清零；20 秒内重新亮屏则保留 |
| 时长口径 | 注视时长可用时以注视为准，否则以亮屏时长为准 |
| 注视心跳 | 超过 180 秒无注视信号即判定不可用，回退亮屏计时 |
| 浮窗 | 纯色全屏 + 大号倒计时数字 + 「暂停活动」按钮，默认 25 秒 |
| 浮窗期间熄屏 | 倒计时继续，不暂停 |
| 浮窗期间屏幕 | 保持常亮（窗口标志），避免 25 秒无操作被系统熄屏 |
| 暂停活动 | 点击暂停当前媒体播放，按钮变为「继续活动」；浮窗结束自动恢复 |
| 来电 | 浮窗期间响铃立即撤掉浮窗，避免遮挡来电界面（需电话状态权限，无权限时按窗口名兜底） |
| 紧急脱出 | 连续按音量下键 5 次 |

## 功耗设计

本项目的功耗约束是硬性要求，实现上做了以下取舍：

1. **零轮询**。计时采用区间结算：只在 `SCREEN_ON` / `SCREEN_OFF` 等真实事件发生时补算上一次结算点到当前的时长，空闲时进程不产生任何 CPU 唤醒。
2. **熄屏判定惰性求值**。熄屏时只记录时刻，下次亮屏才比较差值，熄屏期间不设任何定时器或闹钟。
3. **全应用只有一个到期定时器**，且它只在计时真正推进时存在，熄屏或浮窗期间立即移除。
4. **按键过滤常驻但不产生额外唤醒**。无障碍服务在配置里声明 `flagRequestFilterKeyEvents`，
   浮窗期间的返回与 Home 会被吞掉；过滤本身只在按键发生时才回调，空闲不耗电。
5. **界面刷新随生命周期**。主页每 5 秒刷新一次，仅在 `onResume` 期间运行，`onPause` 立即停止。
6. **限时 WakeLock**、零周期任务，通知渠道为 `IMPORTANCE_MIN` 静默不打扰。
   实测 `FLAG_KEEP_SCREEN_ON` 对无障碍浮窗不生效（`mStayOn` 恒为 false），
   浮窗期间改用 `SCREEN_BRIGHT_WAKE_LOCK`，获取时带 25+15 秒超时，浮窗结束立即释放，
   不会成为常驻唤醒源。

## 消息与权限

- 无障碍服务：提供 `TYPE_ACCESSIBILITY_OVERLAY` 窗口、浮窗期间按键过滤与来电检测，是核心依赖。
- 电话状态：仅在浮窗存续的 25 秒内注册监听，响铃即撤浮窗，用完立即注销。
- Shizuku：执行 `cmd media_session` 控制媒体，并在启动时把应用加入 Doze 白名单。
- 通知：前台服务常驻通知，最低重要性。
- 开机自启：主要保底路径为无障碍服务被系统重新绑定，`BOOT_COMPLETED` 为补充。

## 稳定性

- **开机自启**：重启后无障碍服务由系统自动重新绑定，顺带拉起计时服务。实测重启后进程常驻、计时自动开始。
- **Doze 白名单**：启动时通过 Shizuku 执行 `cmd deviceidle whitelist +包名`，白名单由系统持久化。
- **Shizuku 限制**：无线调试模式下重启手机后 Shizuku 会停止，需在 Shizuku 应用内重新启动服务。
  未启动时媒体控制降级为 `AudioManager` 媒体键，其余功能不受影响。

## 防离开设计

系统不向第三方开放手势拦截能力，且实测 `am task lock` 会连带把屏幕锁上
（LockTask 内部调用 `lockNow`），有密码锁的设备无法自动恢复，因此放弃锁定方案。

现方案分两层：

1. **全屏遮挡**：无障碍 overlay 覆盖状态栏、导航栏与挖孔区域，消费全部触摸。
2. **切走即重置顶**：监听 `TYPE_WINDOW_STATE_CHANGED`，前台一旦换到别的应用就重新挂载浮窗
   （同层窗口的叠放顺序由添加顺序决定），保证浮窗始终压在最上层。

按键层面保留无障碍拦截：三键导航与物理返回、Home 在浮窗期间被吞掉；全面屏手势无法拦截，
但用户滑走后看到的仍是全屏浮窗，实际上无法使用设备。

## 构建

```bash
./gradlew assembleDebug
```

产物位于 `app/build/outputs/apk/debug/app-debug.apk`。

## 目录

```
app/src/main/java/com/eyestrainrelief/
├─ core/    计时常量与状态机
├─ service/ 常驻计时服务、开机自启
├─ access/  无障碍守卫服务
├─ overlay/ 全屏浮窗
└─ ui/      设置与状态界面
```
